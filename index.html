Google Sheet — live team sync

Connect your JOHANNESBURG PACKING BOX Google Sheet so everyone who opens this page shares one live list — no login, no payment.

  1. Open your packing Google Sheet → Extensions → Apps Script.
  2. Delete any code there, click Copy Code.gs above, and paste it in.
  3. Add a Script Property named PORTAL_SYNC_TOKEN with a random token of at least 16 characters.
  4. Deploy → Web app, set “Who has access” to Anyone, and copy the Web App URL. Anyone access plus the token keeps writes restricted.
  5. Paste the URL and the same token below, then press Save URL. Entries sync both ways.
Stored only for this browser tab session. Configure PORTAL_SYNC_TOKEN in Apps Script.

Putting this page on posteroai.com

Three steps and the portal runs on your own domain.

  1. Hosting: upload this page file as index.html to any static host (Netlify, Cloudflare Pages, Vercel, or your domain’s hosting) and point posteroai.com at it. No GPU or server is needed.
  2. Shared data: connect the Google Sheet above — the sheet becomes the one shared list for your whole team.
  3. Done: open posteroai.com on any phone or computer to add boxes, assign containers and print labels.
